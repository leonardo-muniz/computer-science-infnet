# TP3 - Algorithm Analysis and Data Structures

## Overview

This repository contains the implementation of the activities proposed in Performance Test 3 (TP3), covering concepts of recursion, dynamic programming, complexity analysis, and advanced sorting and selection algorithms.

The exercises were developed in Python, focusing on the understanding of recursive mechanisms, optimization through memoization, and analysis of the behavior of classical algorithms such as QuickSort and QuickSelect.

## Exercises

### Exercise 1

Recursive multiplication using only addition operations.

### Exercise 2

Recursive factorization of integers with proper handling of special cases.

### Exercise 3

Recursive exponentiation with support for positive, negative, and zero exponents.

### Exercise 4

Recursive traversal of directories and subdirectories using hierarchical navigation.

### Exercise 5

Recursive generation of combinations for team formation.

### Exercise 6

Recursive implementation of the Knapsack Problem.

### Exercise 7

Complexity analysis of recursive algorithms and identification of redundant calls.

### Exercise 8

Optimization of a recursive algorithm using memoization and dynamic programming.

### Exercise 9

Implementation of the QuickSort algorithm using the divide-and-conquer approach.

### Exercise 10

Instrumentation of QuickSort to count comparisons and copy operations.

### Exercise 11

Implementation of the QuickSelect algorithm for efficient element selection.

### Exercise 12

Experimental comparison between QuickSort and QuickSelect.
